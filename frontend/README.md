# Frontend — Amazon Clone (Version 1)

React 19 single-page application built with Vite and Tailwind CSS.

## Features
- Dynamic product browsing with category filtering
- Responsive navigation bar with search bar and cart count
- Interactive shopping cart drawer
- Instant client-side feedback and toast notifications

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
