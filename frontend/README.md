# Frontend — Amazon Clone (Version 3)

React 19 SPA featuring product reviews, multi-attribute search filters, and order tracking.

## Features
- Interactive customer star ratings and written reviews
- Sidebar filtering (price ranges, minimum rating, category)
- Order status lifecycle timeline (Pending -> Processing -> Shipped -> Delivered)
- Proxied through Nginx reverse proxy

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
