# Frontend — Amazon Clone (Version 2)

React 19 SPA featuring authenticated shopping, persistent user state, and address selection.

## Features
- JWT Authentication (Sign Up, Sign In, Profile)
- Persistent shopping cart synced with backend API
- Wishlist heart toggle with saved state
- Multi-address checkout flow and order history view

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
npm run preview
```
